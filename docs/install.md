# Install Ocarina of Time

Follow the [Ocarina of Time installation guide](../games/oot/docs/install.md) or use the [local MNG Launcher workflow](../maintenance.zh-CN.md).

## Folders

The game App may keep its RomFS inside the bundle. The Launcher uses the work folder recorded in the App for later updates. On this Mac that folder is `/Volumes/MNG-OoT-Work/build`. Mount the work volume before updating to reuse the verified data, shaders and pipelines.
